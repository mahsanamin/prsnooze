# Default profile pictures

Personas by [Draftbit](https://draftbit.com/), obtained from
[DiceBear Personas](https://www.dicebear.com/styles/personas/), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

These unmodified SVG responses were downloaded from the DiceBear 9.x API on
2026-09-10. Seeds and background colors are recorded in
`lib/instance-settings.js`; generation used `radius=18`. Each SVG retains its
original attribution metadata. They are bundled so browsers do not depend on
the DiceBear service or send visitors' image requests to a third party.
